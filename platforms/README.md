# Platform packages

The modpack has separate Packwiz roots for each distribution platform:

- `modrinth/` uses Modrinth metadata and produces `JS Combat Pro-<version>.mrpack`.
- `curseforge/` uses CurseForge metadata where a compatible file exists and produces `JS Combat Pro-<version>.zip`.

Files without a compatible CurseForge release remain bundled in the CurseForge package.
